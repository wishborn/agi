# Wave 3 Channels — live-role picker + info popovers + tabs (v0.4.958-960, s230)

UX-overhaul Wave 3. Owner: free-text roles ("don't make me type"), no
explanations on the dials, "too many panels, no tabs, content too moshed up."

## The live role list was already on the wire — the type just hid it
- The free-text role input was in `comms-channels.tsx` RoleOverridesCard. The
  fix needs the channel's live roles. Backend `/api/channels/discord/state`
  RETURNS `roles: describeGuildRoles(g)` per guild — but the dashboard's shared
  `DiscordChannelState`/`DiscordGuildDescriptor` type OMITS `roles` (only
  settings-channels.tsx has a richer LOCAL type with roles). So: fetch the state
  and read `guilds[].roles` DEFENSIVELY via a cast, rather than retyping the
  shared interface (which other consumers depend on). Filter out @everyone +
  managed roles; store the role NAME (the same kind the free-text stored) so the
  backend matching is unchanged — drop-in replacement.
- Pattern: `RoleOverridesCard` takes an optional `availableRoles` prop → renders
  a PAx `Select` when present, falls back to the text `Input` otherwise. Graceful
  for non-Discord channels.

## Reusable InfoPopover
- `ui/components/ui/info-popover.tsx`: a small `<Info/>` (lucide) on the PAx
  Popover. `ConfigCard` already exposed a `right?: ReactNode` slot, so a
  card-level popover is just `right={<InfoPopover>…</InfoPopover>}` — no card
  surgery. Authored one concise explanation per control (mode, memory scope,
  tool access, auto-moderation, rate limits, role overrides).

## JSX-restructure trap (tabs wrap)
- Wrapping two existing card grids in Tabs via multi-edit got the `<div>` balance
  wrong (an extra `</div>` + missing `</TabsContent></Tabs></div>`). **typecheck +
  build caught it immediately** (esbuild parse). Lesson: when restructuring JSX
  across several edits, run the build right after and reconcile open/close by
  reading the actual post-edit region, not by reasoning abstractly. Kept it
  low-risk: only the LAYOUT moved under tabs; page state / save bar / patch()
  untouched.
