## GitHub API specifics that mattered
- **Contribution metrics**: `head=<user>:<branch>` REQUIRES a branch, so to count
  ALL of the owner's PRs per repo, fetch `pulls?state=all&per_page=100` and filter
  client-side by `pull.user.login === ownerLogin`. merged = `merged_at != null`,
  open = `state === "open"`. Degrade to zeros without token/login.
- **PR comments = ISSUE comments**: a PR's conversation thread is the underlying
  issue's comments — `GET/POST /repos/<org>/<repo>/issues/<n>/comments`. (The
  `/pulls/<n>/comments` API is line-level review comments, a different thing.)
- `githubHeaders(token: string)` is typed for a non-null string; the owner token
  from `readOwnerGithub` is `string | null` → pass `token ?? ""`. typecheck (not
  lint) catches the mismatch — run typecheck before committing backend GitHub code.
